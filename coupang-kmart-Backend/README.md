# Coupang KMART Backend

This is the backend for the Coupang KMART project.

## Directory Structure
- \`src/config\`: DB & app config
- \`src/controllers\`: Business logic
- \`src/models\`: Database schemas
- \`src/routes\`: API routes
- \`src/middlewares\`: Auth, error handling
- \`src/services\`: Complex logic (optional)
- \`src/utils\`: Helper functions
- \`src/modules\`: Feature-based modules (optional advanced)

## Setup
1. Run \`npm install\`
2. Run \`npm run dev\` to start local development server
